# SDCハンドブック 日本語訳

*Handbook on Statistical Disclosure Control (2nd Edition)* の非公式日本語訳です。

統計的開示制御(Statistical Disclosure Control, SDC)― ミクロデータ・表形式データの匿名化・開示リスク評価・保護手法について、Eurostatの卓越センター(Centre of Excellence on SDC, STACEプロジェクト)がまとめた技術ハンドブックの全文を日本語に翻訳しています。
